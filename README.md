# AION 2 HUD Atelier

By **GalaxyBunny Studio**.

A local browser editor for HUD layout mockups: drag blocks, align, resize, hide, duplicate, lock, change mockup colors and shapes, use templates, save JSON projects and export SVG images.

Open **index.html** in a modern browser. No installation or server is required. Keep the files together.

## Important limits

This experimental version does **not** apply changes to AION 2, replace game graphics, or generate modified game presets. Mockup sizes and shapes are not guarantees of game support. The game-preset reader can inspect the supported Base64/XOR JSON format and download the unchanged original.

## Languages

30 languages are available on the landing page and in the editor. Translations are machine-assisted and have not been reviewed by native speakers. French is the source language. Technical JSON keys, custom names, filenames and game data are preserved. The license text is supplied in English.

French, English, Spanish, Portuguese, German, Italian, Dutch, Polish, Russian, Ukrainian, Japanese, Korean, Simplified Chinese, Arabic, Turkish, Hindi, Bengali, Indonesian, Vietnamese, Thai, Swedish, Norwegian, Danish, Finnish, Czech, Romanian, Greek, Hungarian, Hebrew and Malay.

## Privacy

Files are processed in the browser. No file upload, analytics, network translation service or external font is used at runtime. Automatic project recovery and language settings use browser local storage. Public assets contain no personal game export, screenshot or local computer path.
